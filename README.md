# GPU Explorer

**在线页面：https://yingxu-work.github.io/gpu-explorer/**

**一颗能拆开、运行、解释、比较的“透明 CPU / GPU”。**

## 最开始的想法

这是一部可以操作的 CPU / GPU 教科书，不是讲义，也不是参数表。它的起点是：看芯片讲解视频的时候，观众只能跟着镜头走，没法自己停下来、拆开一颗芯片、追踪一个计算到底是怎么跑完的。GPU Explorer 要做的，就是把这个过程交到读者手里。

三个入口，共用同一套模型，切换时不丢选中对象和上下文：

| 入口 | 读者做什么 |
| --- | --- |
| **拆开看看** | 从封装进入芯片和计算单元，查看部件、连接、共享范围与用途。 |
| **让它做点事** | 运行一个教学例子，追踪输入到结果，观察工作分配、计算与数据搬运。 |
| **和另一颗比较** | 保留当前研究的问题，比较另一代或另一家架构如何解决它。 |

两条核心学习路径，外加两条扩展路径：

1. **一次矩阵乘法如何完成。** 点选 C[3,7]，查看参与的输入、工作划分、数据复用、执行与等待。
2. **一个像素如何画出来。** 从结果倒查几何、采样和处理阶段，理解图形任务与硬件的联系。
3. **一次页表翻译如何完成。** 从虚拟地址出发，经过 TLB、PGD、PUD、PMD、PTE 走到物理内存与缓存。
4. **芯片逻辑堆叠长什么样。** 以剖面 + 俯视图看逻辑层、键合层、内存与缓存层的堆叠关系。

灵感来源（只借交互与版式，不抄内容与主题）：极客湾（Geekerwan）那种“先给结论、再比家族、再看内部结构、最后看实测”的长视频讲解顺序；bbycroft.net/llm 那种一步一步走、每步都停下来等读者按继续的交互；PC Anatomy 与 GEX 的深色全屏应用壳（左侧章节导航、中间 3D 画布、右侧检查器、底部时间轴）。

## 现在的样子（2026-11-02）

- 深色全屏应用壳：顶部栏、左侧旅程与型号导航、中间可交互 3D 画布、右侧步骤检查器、底部时间轴。
- 真实的 Three.js / WebGL 3D 场景（本地打包，无 CDN）：拖动旋转、滚轮缩放、点击选中、拆开滑杆与自动拆开；步骤变化时高亮对应部件，相机不乱跳。
- 步骤控制：上一步 / 下一步 / 播放 / 回到开头，时间轴上每个步骤都是可直接点击的块；另有“先预测、再播放”的短挑战与折叠的代码片段。
- 键盘可用：部件列表可用方向键移动、回车选中，画布聚焦时方向键移动选中，空格不再误触播放。
- 手机与平板：375px 与 768px 宽度下导航收成横向滑动行，画布按 3:2 完整框住芯片，底部播放条吸底；桌面版不受影响。
- 旅程：矩阵乘法 C[3,7]（8 步）、页表遍历（7 步）、像素着色（8 步）、芯片堆叠（8 步）；视图：结构 / 工作 / 数据 / 时间，切换不丢步骤与选中状态，状态写在 URL 里。
- 型号：H100、A100、RTX 5090、MI300X、A20 Pro（示意）、Snapdragon 移动 SoC（示意）；对比模式可保留当前问题换一颗型号对照。

## 型号准确度：每个图分清型号

- **A100（GA100 / Ampere）**：按 NVIDIA 官方 Ampere 文章的图 4（全芯片）与图 5（SM）重建——7 个 GPC 组、L2 40MB 分 2 区、HBM2 5 叠、每 SM 64 FP32 / 32 FP64 / 64 INT32 / 4 张量核心、L1 与共享 192KB/SM。颜色直接从官方图采样。
- **H100（GH100 / Hopper）**：按 NVIDIA 官方 Hopper 文章的图重建——8 个 GPC、L2 60MB 分 2 区、HBM3 6 叠、每 SM 128 FP32 / 4 张量核心、256KB L1 与共享、Tensor Memory Accelerator 条带。颜色同样从官方图采样。
- **没有用的传言**：2022 年 2 月 7 日 HotHardware 转引 Chiphell 爆料的“GH100 超过 1400 亿晶体管”是发布前传言，不在应用里（只有一条测试防它混进来）；H100 官方数为 800 亿晶体管、814 平方毫米。
- **标明的简化**：教学图里 A100 画 28 格、H100 画 32 格，不等于真实的 108 / 144 个 SM；Shared Memory 画成一条带，真实是每 SM 一份；HBM 的东西分法是教学排布；颜色跟官方教学图，不等于真实硅片颜色。应用内每个型号说明都写明了这一点。
- **合规**：本页面为非官方教学模型，与 NVIDIA 无隶属或认可关系；型号名称仅用于标示所讲解的硬件，示意图为教学示意，非 NVIDIA 官方图稿；仓库里没有 NVIDIA 的 logo 与原图。

## 本地运行与测试

```sh
python3 -m http.server 18910 --bind 127.0.0.1
# 打开 http://127.0.0.1:18910/
./run_tests.sh
```

- `index.html` / `app.js` / `state.js` / `scene-map.js` / `scene3d.js` / `styles.css`：静态应用本体，无后端、无 GPU 计算；Three.js 本地打包在 `three/`。
- `tests/`：单元测试与集成测试；`docs/`：项目构想。
- 部署：GitHub Pages，从 main 分支根目录发布；本地开发用的 gpuserver 部署只绑 127.0.0.1:18910，不对外暴露。
