# GPU Explorer

**一颗能拆开、运行、解释、比较的“透明 GPU”。**

GPU Explorer 的目标是一部可以操作的 GPU 教科书：从板卡与封装进入内部架构，跟随具体任务观察工作分配、计算与数据搬运，并比较不同架构的设计选择。

**当前状态：构想与产品设计阶段。此仓库目前保存项目方向，还没有可运行应用。**  
首次记录：2026-11-01（Asia/Singapore）。

## 三个入口

| 入口 | 用户做什么 |
| --- | --- |
| **拆开看看** | 从封装进入芯片和计算单元，查看部件、连接、共享范围与用途。 |
| **让它做点事** | 运行一个教学例子，追踪输入到结果，观察代码、硬件资源和执行状态。 |
| **和另一颗比较** | 保留当前研究的问题，比较另一代或另一家架构如何解决它。 |

三个入口使用同一套模型与知识，切换视图时保留选中对象和上下文。

## 核心体验

两条完整的学习旅程：

1. **一次矩阵乘法如何完成。** 点选 C[3,7]，查看参与的输入、工作划分、数据复用、执行与等待，并比较不同实现。
2. **一个像素如何画出来。** 从结果倒查相关几何、采样和处理阶段，理解图形任务与硬件的联系。

重要交互包括：

- 连续进入不同尺度，同时保留全局位置。
- 结构、工作分配、数据、等待、资源占用等视图。
- 顺着输入追踪用途，或从结果倒查依赖。
- 修改访问模式、block 大小、tile 或工作量，对照前后变化。
- 先预测、再播放的短挑战。
- 可分享、带注释的讲解路径。

## 内容与硬件方向

内容覆盖物理结构、内部架构、工作分配、执行过程、数据与内存、实际任务。每个重要部件应解释职责、输入输出、协作关系、共享范围和资源限制，并配有操作示例。

建议先以 **H100** 做深入计算主线，再加入 **消费级 RTX** 的图形主线和 **AMD MI300X** 的封装与架构比较。具体 SKU、实施顺序和排期仍待确定。

3D 重点用于空间关系、封装、堆叠和层级；线程、地址、依赖和时间关系采用适合阅读的二维表达。硬件资源、软件工作和执行时间保持清晰区分。

## 第一版建议

第一版围绕一颗可完整探索的 GPU，串起结构探索、向量计算、warp 分支、访存模式、矩阵乘法，以及资源占用与工作覆盖等示例。模型、代码和时间轴应方便同时对照。

**这是建议范围，不是已承诺完成的功能清单。** 图形旅程、跨架构比较、代际演化、讲解制作与“自己设计 GPU”模式将在主线成立后扩展。
