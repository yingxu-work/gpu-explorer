## 七个探索视图

视图是有分支的组件导航，左侧编号不代表所有部件沿同一条层级依次嵌套。

| 视图 | 主要可见结构 | 返回路径 |
| --- | --- | --- |
| SXM 模组 | PCB、GPU 封装、HBM、供电器件、背面连接器 | 根视图 |
| 芯片封装 | 有机基板、硅中介层、GPU 裸片、五组有源 HBM | SXM 模组 |
| GPU Die | 计算阵列、共享 L2、片上互连的功能组织 | 芯片封装 |
| SM | 四个子分区、调度与派发、寄存器、执行资源、LD/ST、共用 L1 / Shared | GPU Die |
| HBM 内存 | DRAM 叠层、bank 阵列示意、TSV、微凸点、底部接口、并行通道、中介层连接 | 芯片封装 |
| 供电模块 | 输入母线、功率级、电感、输出电容、公共供电轨、控制与反馈 | SXM 模组 |
| PCB / SXM 互连 | 铜层与参考平面、普通通孔、差分对、接触阵列 | SXM 模组 |

HBM 的通道数与叠层数分开说明。HBM3 接口展示 16 × 64 bit、HBM2e 展示 8 × 128 bit，均为 1024 bit；图中的八层 DRAM 是代表性教学剖面。PCB 普通通孔与穿过硅片的 TSV 分开命名。

供电视图用宽母线连接输入、功率级、电感和公共输出轨，控制与采样采用独立细线；互连视图增加成对导体、层间通孔与接触焊盘。它们用于读懂连接关系，未模拟开关波形、传输线或电源完整性。

## 八步动画各自表达什么

第 01–03 步有可见的目标或关系，但不把数学依赖、工作分配冒充物理搬运。第 04 步开始显示数据移动。

| 步骤 | 主要视图 | 可见线索与含义 | 常驻路径说明 |
| --- | --- | --- | --- |
| 01 定位结果 | SXM 模组 | A、B、C 的显存区域标记；虚线只建立依赖 | 定位结果；尚未计算 |
| 02 一行乘一列 | HBM | A 行、B 列与 C 目标；虚线没有搬运脉冲 | 输入仍在 HBM，尚未搬运 |
| 03 分配工作 | GPU Die | 输出 tile / CTA 与选中 SM 的虚线关联 | 工作落到 SM；这不是数据传输 |
| 04 搬入第一块 | 芯片封装 | HBM 经中介层、GPU 侧接口与 L2 到 SM 的分段路径 | 标明“教学透视” |
| 05 线程协作 | SM | 调度器到派发单元的控制路径；Shared、LD/ST、寄存器的操作数路径 | 指令派发与数据搬运分开显示 |
| 06 第一轮乘加 | SM | 操作数到 Tensor Core，再到累加器 | 标量内积展开为 0 → 19 |
| 07 换块并累加 | SM | 下一块搬入与后续乘加，保留已有累加值 | 19 → 37 |
| 08 写回结果 | 芯片封装 | SM / 累加器经缓存层级回到 HBM 的 C | C[3,7] = 37 |

路径采用贴近模型的直角带状互连、方向标记与短段亮起，SM 内路径加宽。封装搬运和写回阶段对硅片盖层使用明确标出的教学透视，避免内部路径被实心表面完全遮住。它不表示芯片材料本身透明。

画布中的位置标记与画布下方的步骤路径共同保留来源、去向和阶段说明；动画完成后，路径与终点仍可阅读。全屏包含整个场景面板，使这段说明也保留在全屏中。

控制信号不被画成矩阵操作数穿过 warp scheduler。SM 布局沿用公开功能图的资源归属，不能由图中距离推断 scheduler 与 L1 在真实硅片上的物理间距。Hopper TMA 与 A100 异步搬运分开表达；MMA 的实际操作数来源、线程与寄存器映射依指令和内核而异。

## 相机与教学状态

| 操作 | 教学状态与进度 | 场景处理 |
| --- | --- | --- |
| 3D / TOP / SIDE | 保留当前步骤、进度、暂停或序列播放；不增加教学重建版本 | 按当前组件重新适配镜头 |
| 拖动旋转、平移、滚轮缩放 | 保留教学；暂停时不会自行恢复播放 | 相机变为自由观察 |
| 标签开关、全屏 | 保留教学上下文 | 改变展示方式 |
| 点选、双击进入部件、切换硬件视图、隔离、拆解 | 进入自由探索并暂停教学 | 以用户选择的组件为准 |
| 顶部“跟着算一次” | 回到所保留的当前步骤并重新演示 | 停止自动拆解、合拢、清除隔离与选中、恢复标准视图 |
| 时间轴、前后步、旅程入口 | 通过统一入口准备所选教学步骤 | 避免残留上一探索场景的状态 |

场景自身触发层级切换时，同步相机预设状态，避免按钮仍显示 TOP 而模型已转回 3D。同层级通知保留当前预设。组件目录与画布方向键按当前物理视图选择组件，避免在供电或 PCB 视图选中不可见的 GEMM 数据别名。

SM 是功能组织图；在 SM 使用机械拆解会返回封装。HBM、供电、PCB / SXM 是各自的组件剖面，拆解保留在相应视图。

## 事实与重建的边界

- H100 SXM 80GB 与 A100 SXM 80GB 的产品规格沿用 [README](../README.md) 的口径；完整 GPU 设计的最大资源数不等同于当前产品启用资源数。
- 外部形态为程序化重建，未使用厂商 CAD。两代产品共用近似外形，不由此推断其 PCB、连接器或机械尺寸完全相同。
- SM、L2 和片上路径是功能组织与教学路由，不是真实晶体管版图、物理距离或金属布线网表。参见 [SM 来源与布局口径](SM_LAYOUT_SOURCES.md)。
- HBM 八层剖面、bank 与 TSV 排列、六相供电、PCB 层叠和接触阵列均为示意；没有声称复原特定显存供应商、供电控制器、电路相数或 SXM 引脚定义。右侧 HBM PHY / 控制器块表示 GPU 内部接口角色，不是新增的封装外芯片。
- 数值实验用小矩阵解释分块与内积；逐项标量累加和 32 lane 图不等同于真实 MMA 的逐线程映射。动画时间不代表延迟、带宽或性能实测。
- 页表、像素和逻辑堆叠仍是独立概念实验，不表示 H100 含 CPU 核、显示输出或上下堆叠逻辑层。
