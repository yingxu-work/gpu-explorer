# 交互微调与回归 — 2026-11-02

目标：修复自由探索与逐步计算交叉操作时的状态泄漏，减少常驻文字，并核实 SM 组织和数据线路。

## 交互约定

- 硬件操作（层级、选中、隔离、旋转、相机预设、拆解）进入自由探索，暂停教学；教学信号停止。
- 「跟着算一次」始终回到当前步骤：合拢、停止自动拆解、取消隔离和用户选中，恢复该步镜头并重播。重复点击也生效。
- 旅程入口从第一步开始；时间轴与前后步恢复所选步骤；只重播当前步会取消完整序列。
- 最后一步点击完整播放从第一步重新开始；当前步重播保留在最后一步。
- SM 是功能结构图，机械拆解从 SM 切回封装；不把执行资源画成可机械分离的芯片堆。
- 标签与全屏保持教学上下文；型号切换清除旧型号的物理选中与隔离。
- 探索链接恢复尺度、拆解值和有效部件；教学链接以步骤标准状态为准。无效型号/部件参数安全归一化。

## 本轮实际抓到并修复的问题

1. SM 隔离后点教学按钮仍残留隔离、拆解和旧镜头，镜头跟随还被永久关闭。
2. 自动拆解在进入教学后继续修改装配；时间轴在探索中不恢复教学面板。
3. “重播当前步”仍保持完整序列播放，随后跳到下一步。
4. 隔离一个 SM 部件后从目录选择 HBM：按钮显示隔离，实际场景已取消。
5. 返回步骤时场景准备清掉刚创建的信号线路；准备后重新绑定教学内容。
6. 最后一步动画未完时点击完整播放，不会回到第一步。
7. 哈希变更忽略拆解/部件，或接受无效对照和部件；现在校验并恢复。
8. 复位、关闭选中卡片、Escape、切换型号和缩放后，按钮/场景/选中状态不同步。
9. 减少动态效果偏好下的序列可能卡在完成状态，现使用有限停留时间推进。
