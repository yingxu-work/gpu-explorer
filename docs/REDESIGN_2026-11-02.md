# GPU Explorer 改版 — 2026-11-02

本轮目标：让硬件具有可识别的机器外形，使用连续的层级探索；将矩阵乘法连接成动画、数学与文字同步的完整旅程。

## 实现

- 用程序化 SXM 模组替换原先的彩色盒子场景：PCB、供电、互连、基板、中介层、GPU 裸片、五组有源 HBM、裸片逻辑阵列和放大的 SM。
- 四尺度进入与面包屑；点选、双击聚焦、隔离、标签、视角预设、复位和连续拆解。
- 界面区分硬件解剖与逐步学习；主要操作、部件说明和学习进度有固定位置。
- 数值 GEMM：`A[3] = [2,1,3,2,4,1,2,3]`；`B[:,7] = [1,3,2,4,1,2,3,2]`。乘积为 `[2,3,6,8,4,2,6,6]`，两轮 K-tile 的和为 `19 + 18 = 37`。
- 32 lane 图表示组织，不声称模拟 Tensor Core 指令映射。标量内积与真实矩阵片段 MMA 的差别在教学文本和伪代码中明确说明。
- 页表实验使用 9 位索引掩码和 12 位页内偏移；宽整数伪代码不依赖 JavaScript 的 32 位移位。
- 型号入口收敛到 H100/A100 SXM 80GB。旧型号的状态解析保留兼容，界面选择不提供未完成的其它实物。

## 内容口径

H100 SXM 为 132 SM、50MB L2、80GB HBM3、五组有源堆栈。A100 SXM 80GB 为 108 SM、40MB L2、80GB HBM2e、五组有源堆栈。完整 GH100 与实际 H100 SKU 不再混作同一配置。

外观是近似重建；元件和走线非 CAD。内部逻辑图、SM 分布、禁用单元位置及拆解间距为教学布局。两代板卡共用近似外形，不代表机械尺寸相同。页表、像素和逻辑堆叠为独立概念实验，不被投射为 H100 的物理功能。

来源见 [README](../README.md#官方来源)。
