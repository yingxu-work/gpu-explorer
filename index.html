MODEL NOTES & SOURCES
画得像，也要讲得准。
外部形态是基于公开硬件外观与官方架构资料的程序化重建，没有使用厂家 CAD。被动元件与走线位置为近似排布。
H100 SXM 80GB：132 SM、50MB L2、五组 HBM3。256KB 是每 SM 的 L1 / Shared 合计容量。完整 GH100 的 144 SM、60MB、六组 HBM 不是本标本的可用规格。
A100 SXM 80GB：108 SM、40MB L2、五组 HBM2e。芯片内部阵列及连线为教学布局。
页表示例使用通用 x86-64 四级页表；像素旅程是通用图形管线；逻辑堆叠旅程是概念剖面。它们不表示 H100 具备 CPU 核、显示输出或上下堆叠逻辑层。
配套组件：HBM 叠层、多相供电和 PCB 剖面用于说明结构与原理；层数、相数、元件坐标和引脚排布不代表特定厂家产品的内部设计。
SM 布局：按 NVIDIA 功能框图组织四个子分区，补出 LD/ST、派发与内部互连；图中间距不表示真实硅片上的物理距离。L1 指令缓存与 L1 数据缓存 / 共享内存分开标示。
GEMM 小矩阵解释内积与分块；32 lane 图表示分工，不是 Tensor Core 的逐 lane 寄存器映射。动画时间均为教学节奏。
